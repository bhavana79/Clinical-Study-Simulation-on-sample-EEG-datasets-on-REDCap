# Clinical-Study-Simulation-on-sample-EEG-datasets-on-REDCap

Work done:
> Simulated a longitudinal research study protocol within a REDCap database environment to manage
multi-event patient records.
> Sourced raw public electroencephalogram (EEG) datasets to engineer a realistic clinical database
schema.
> Developed Python (Pandas/NumPy) scripts to programmatically screen incoming data dictionaries,
isolate entry anomalies, and flag clinical field discrepancies.
> Configured data export for migrating cleansed datasets into R software for statistical analysis.
